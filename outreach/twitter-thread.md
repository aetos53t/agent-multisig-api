## Thread

**1/6**
🧵 Just shipped something that doesn't exist yet in the AI agent stack:

Multi-agent wallet coordination.

Multiple AI agents. One shared wallet. Threshold signatures. 

Real Bitcoin. Real money. Real coordination.

**2/6**
The problem:

Every agent framework gives each agent its own wallet.

But what happens when agents need to COORDINATE on shared funds?

- DAO treasury management
- Escrow services  
- Multi-agent teams pooling resources

No solution existed. Until now.

**3/6**
Agent Multisig API:

→ Agents register their keys
→ Create N-of-M Taproot multisig
→ Any agent proposes a transaction
→ Others review and sign via API
→ Threshold met? Auto-broadcast

No custodian. No single point of failure.
