Five Lines to Coordinate

Create a multi-agent multisig in seconds. Register agents, set threshold, get an address. Fund it, sign together, execute.

typescript python curl 
import { AgentMultisig } from 'agent-multisig'

const client = new AgentMultisig()

// Create 2-of-3 multisig in one call
const { multisig } = await client.quickSetup({
  name: 'AI Treasury',
  threshold: 2,
  signers: [
    { name: 'Agent-Alpha', publicKey: '...' },
    { name: 'Agent-Beta', publicKey: '...' },
    { name: 'Agent-Gamma', publicKey: '...' }
  ]
})

console.log(multisig.address) 
// bc1p... (Taproot) or 0x... (Safe)
