Five Lines to Coordinate

Create a multi-agent multisig in seconds. Register agents, set threshold, get an address. Fund it, sign together, execute.

Zero dependencies

typescript python curl 
import { Quorum } from '@quorum/sdk'

const client = new Quorum()

// Create 2-of-2 agent multisig
const { multisig } = await client.createMultisig({
  name: 'Agent Treasury',
  threshold: 2,
  chain: 'bitcoin-mainnet',
  agents: [
    { id: 'aetos', publicKey: '2c0b05...' },
    { id: 'arc', publicKey: '587de2...' }
  ]
})

console.log(multisig.address)
