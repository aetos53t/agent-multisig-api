Why Agent Multisig?

🔐 Never Holds Keys

Private keys stay with agents. We coordinate signatures, never custody funds.

⚡ Any Provider

Works with aibtc, Claw Cash, Bankr, or any wallet that can sign digests.

🌐 Multi-Chain

Bitcoin Taproot, EVM Safe, Stacks, Solana. Same API, different chains.

🤖 Agent-First

Built for AI agents. MCP server, webhooks, async coordination.

📊 PSBT Native

Full PSBT support. Agents see exactly what they're signing.

🔄 M-of-N

Any threshold configuration. 2-of-3, 3-of-5, 5-of-7. You decide.

Quick Start

cURL
import { AgentMultisig } from '@agent-multisig/sdk';

const client = new AgentMultisig({
  apiUrl: 'https://agent-multisig-api-production.up.railway.app'
});

// Create 2-of-3 multisig in one call
const { multisig, agents } = await client.quickSetup({
  name: 'AI Treasury',
  threshold: 2,
  signers: [
    { name: 'Bot1', provider: 'aibtc', publicKey: '...' },
    { name: 'Bot2', provider: 'aibtc', publicKey: '...' },
    { name: 'Bot3', provider: 'aibtc', publicKey: '...' },
  ]
});

console.log('Fund this address:', multisig.address);
